## 0. 這個平台是什麼

銘傳大學圖書館的 AI 基地。對學生與教職員提供三件事：

| 想做什麼 | 平台提供的 |
|---|---|
| 用大型語言模型（聊天、寫作、整理文件） | 導向學校採購的 **MYAI** 平台，並管理每個人的點數 |
| 訓練自己的模型 | 學校的 **GPU**，可以「交給平台跑」或「自己開實驗室寫」 |
| 學怎麼用 | 範例、文件庫、站內助手「小基」 |

平台**自己不做對話模型的推論**給一般使用者 —— 那一段是 MYAI 廠商提供的。
平台負責的是帳號、額度、GPU 排程、以及把這些事湊在一起。

### 三個入口

| 入口 | 網址 | 誰用 |
|---|---|---|
| 使用者端 | `http://<主機>/` → 自動轉 `/V1/` | 學生、教師、職員 |
| 管理端 | `http://<主機>:8888/` → 自動轉 `/V1/` | 管理員 |
| API | `http://<主機>/api/v1/...` | 兩端的前端、GPU worker |

> ⚠ 管理端**不對使用者埠開放**。`:80` 上打 `/api/v1/admin/...` 不會通 ——
> 那是刻意的，見 `infrastructure/nginx.conf` 的說明。

## 1. 使用者端

導覽列分成「首頁」加三個分類，分類的判準是**使用者帶著什麼念頭來**，
不是功能相似度：

```
首頁 · 想做點什麼▾ · 看我的東西▾ · 不知道怎麼做▾        [中][EN] [學號▾]
```

### 1.1 首頁

- **公告** —— 最多 7 則，置頂的排最前。超過 7 則才出現「看全部公告」。
- **分組卡片** —— 三組共 8 張，是「全部去處的地圖」。

> ⚠ 首頁**沒有**額度卡。額度在「體驗大模型」那一頁 ——
> 兩邊都放的話就是同一台狀態機的兩份實作。

### 1.2 體驗大模型（`myai.html`）

- 顯示**我的 MYAI 點數**，額度偏低／用完時整張卡變色
- 主要動作「前往 MYAI 問 AI」：先開廠商的登出頁，1 秒後轉登入頁
  （確保是這位學生登入，不是沿用上一個人的 session）
- 額度不足時給三個下一步：看用在哪、如何申請額度、**向管理員申請額度**
  （走既有的問題回報，不另開第二個收件匣）
- **初始密碼**：開通後保留期內顯示帳號與初始密碼，可一鍵複製
  - 「我已經改好密碼了」會**立即銷毀**伺服器上的暫存密碼，不可逆
  - 沒有密碼可看時整區不出現，也不留訊息

**限制**
- 彈出視窗被瀏覽器擋下時會給一個可點的連結，不會靜默失敗
- 還沒開通的人：主要動作**停用**，並給問題回報的出口

### 1.3 體驗現有模型訓練（`gpu.html`）

「做出一個能分辨貓和狗的模型」的引導頁。兩條路：

| 路 | 適合 |
|---|---|
| 用我們準備好的範例 | 第一次來、手上沒有資料 |
| 我有分好類的圖片，交給平台訓練（`train.html`） | 有資料、不想寫程式 |

三步驟預覽（準備資料 → 在實驗室裡跑 → 看結果）是**預期管理**，不可點。

### 1.4 程式實驗室（`lab.html`）

瀏覽器裡的 VS Code（code-server）。

- **多份存檔**：可以有好幾個各自獨立的工作區，一次只開一份；
  切換時舊的會關閉，**檔案全部保留**
- **GPU 勾選**：預設不勾。勾了才佔卡，借不到時後端會講出是誰在用
- **時間限制**：借了 GPU 有最長借用時間（預設 120 分鐘），
  到期前 30／10／5 分鐘會警告，VS Code 內也看得到
- **每日額度**：依角色有每日使用時間上限，剩餘時間顯示在卡片上
- **磁碟**：顯示「用了多少 / 上限多少」，用量是即時量的不是每日快照

**限制**
- 閒置一段時間會自動關閉（檔案保留）
- 超出磁碟配額會被凍結，開不了實驗室

### 1.5 我的訓練進度（`jobs.html`）

送出去的訓練任務清單與結果。可以下載訓練好的模型檔。

- **排隊位置**只在真的排隊時顯示（用派工端自己的排序與池別篩選算出來）

### 1.6 我的歷史資料訓練（`datasets.html`）

訓練用的圖片資料集，上傳與管理。每人 2 GB 配額。

### 1.7 使用量明細（`usage.html`）

- 每日消耗趨勢
- 我用了哪些模型／工具

### 1.8 公告（`news.html`）

- 內文的**網址會自動變成可點的連結**（只認網址，不吃 HTML）
- **附件**可下載（pdf / docx / xlsx / pptx / png / jpg / zip）
- 有英文版的公告在英文介面顯示英文；沒有英文版的退回中文

### 1.9 問題回報（`report.html`）

- 有主旨與類別
- 管理員回覆後**變成唯讀**，使用者看得到回覆
- 🚫 **刻意不通知**、**只能回一則**（見 04-operations）

### 1.10 文件庫（`docs.html`）

同學的作品與教學影片。
⚠ **沒有內容時整個入口不出現** —— 連到空頁比沒有連結更糟。

### 1.11 小基（站內助手）

浮在右下角，兩種模式：

| 模式 | 需要登入 | 做什麼 |
|---|---|---|
| 客服 | 否 | 回答「這個平台怎麼用」，答案來自知識庫（RAG） |
| 程式家教 | 是 | 讀你自己在實驗室裡的檔案，教你改 |

### 1.12 顯示設定

語言（中／英）、字級、色系。**跟帳號走**，換一台機器登入仍然是你的設定。

- 語言切換在頂部列（切語言是當下就想做的事，不該先開一層選單）
- 字級用百分比，相對於**你自己瀏覽器的字級設定**

## 2. 管理端

五個分頁：總覽、帳號、平台設定、訊息、數據。

### 2.1 帳號

- 使用者清單（本機 / SSO 兩種來源分頁）
- 建立、停用、刪除、改角色與管理權限
- **臨時帳號**：給校外人士、長官視察用，到期自動停用
- **廠商帳號對應**：同步 MYAI 帳號、自動配對、CSV 批次建立對應
- 個別加點、強制關閉某人的實驗室

> ⚠ **刪除帳號**會把 Lab 存檔封存（期限內可還原），其餘資料消失。

### 2.2 平台設定

| 區塊 | 內容 |
|---|---|
| 營運設定 | 7 個旋鈕，**改完立刻生效不用重啟** |
| 告警信 | 系統自己出事時寄給誰（收件人全部留空 = 完全不寄） |
| 模型 | 可用的模型清單 |
| GPU 節點 | 每台節點的狀態、可排程時段、開關、池別覆蓋 |
| 外部 AI | 小基用哪個模型 |
| 廠商模型代碼對應 | 把廠商的原始代碼（如 `gpt_5_6_sol`）翻成看得懂的名字 |
| 手動補齊點數 | 把所有綁定帳號補到同一個水位 |
| 組織對照表 | 學系 → 學院 / 行政單位 / 校區，可匯出匯入 |

**設定分四組**：平台營運、MYAI 廠商整合、小基（RAG）、寄信（SMTP）。

> 🔴 有**兩個設定刻意從畫面隱藏**：`monthly_token_limit` 與 `token_reset_day`。
> 它們是**平台自己的** Token 額度，與學生在用的 MYAI 點數無關 ——
> 並排時接手的人會以為調它們就能改學生的額度，而調了不會有任何效果。
> 隱藏 ≠ 停用：那兩個功能照常運作。要調請改 `.env`。

### 2.3 訊息

- **問題回報**：清單、彈窗檢視、回覆、改狀態、依類別篩選
- **公告**：新增／編輯（彈窗）、置頂、公開與否、**中英兩版並排編輯**、附件

### 2.4 數據

| 區塊 | 內容 |
|---|---|
| MYAI 點數消耗 | 來自廠商交易日誌，逐筆含模型 |
| 訓練任務 | 送出的任務統計 |
| **各分類使用** | 依學系／學院／行政單位分組的使用數據與兩種比例 |

各分類那張表的欄位分兩塊：

```
        │      這一組的人       │            用了多少
 學系   │ 人數 │ 有用的人 │ 滲透率 │ MYAI次數 │ MYAI點數 │ 訓練 │ Lab·GPU │ Lab·CPU │ 登入 │ Token
```

- **佔比**（括號裡的 %）= 這一組佔全平台的幾 % → 看「誰貢獻最多」
- **滲透率** = 有用的人 ÷ 這一組在平台上的人數 → 看「哪一組還沒推開」

> ⚠ 三件事文件與介面都要講明：
> 1. **滲透率的分母是「登入過平台的人」**，不是全系人數 —— 這個數字偏高
> 2. **「有用的人」是下限** —— 跨四張表去重在資料庫端做不到，取各項最大值
> 3. **MYAI 次數與 Lab 的 GPU/CPU 之分是 2026-08-30 才開始記的** ——
>    在那之前的 0 是「還沒開始記」，不是「沒有人用」

## 3. 系統邊界（刻意不做的事）

這一節列的**不是待辦**，是決定。日後想改請先看理由。

| 事 | 為什麼不做 |
|---|---|
| 問題回報不通知使用者 | 通知的成本落在管理員身上，而回報量不大 |
| 文件庫沒內容時不出現入口 | 連到空頁比沒有連結更糟 |
| 公告附件不接受 `.html` / `.svg` | 那兩種會在**我們自己的網域下**執行 script |
| 公告附件刪除不封存 | 那是管理員手上已經有的東西的副本，不像 Lab 存檔沒了救不回 |
| 行政單位不顯示英文名 | 英文名只有 53/97，做了會讓同一欄一半英文一半中文 |
| 不記錄跳轉來源 IP | 統計要回答「哪個系在用」，`user_id` 就推得出來 |
| 不預測 email 真假 | 有地址就寄，退件才是事實 |
