## 0. 這個平台是什麼

銘傳大學圖書館的 AI 基地。對學生與教職員提供三件事：

| 想做什麼 | 平台提供的 |
|---|---|
| 用大型語言模型（聊天、寫作、整理文件） | 導向學校採購的 **MYAI** 平台，並管理每個人的點數 |
| 訓練自己的模型 | 學校的 **GPU**，可以「交給平台跑」或「自己開實驗室寫」 |
| 學怎麼用 | 範例、文件庫、站內助手「小基」 |

平台**自己不做對話模型的推論**給一般使用者 —— 那一段是 MYAI 廠商提供的。
平台負責的是帳號、額度、GPU 排程、以及把這些事湊在一起。

### 三個入口

| 入口 | 網址 | 誰用 |
|---|---|---|
| 使用者端 | `http://<主機>/` → 自動轉 `/V1/` | 學生、教師、職員 |
| 管理端 | `https://ai.lib.mcu.edu.tw:8888/` → 自動轉 `/V1/` | 管理員 |
| API | `http://<主機>/api/v1/...` | 兩端的前端、GPU worker |

> ⚠ 管理端**不對使用者埠開放**。`:80` 上打 `/api/v1/admin/...` 不會通 ——
> 那是刻意的，見 `infrastructure/nginx.conf` 的說明。

## 1. 使用者端

導覽列分成「首頁」加三個分類，分類的判準是**使用者帶著什麼念頭來**，
不是功能相似度：

```
首頁 · AI 工具一把罩▾ · 個人使用紀錄▾ · 資源與回報▾        [中][EN] [學號▾]
```

### 1.1 首頁

- **公告** —— 最多 7 則，置頂的排最前。超過 7 則才出現「看全部公告」。
- **分組卡片** —— 三組共 8 張，是「全部去處的地圖」。

> ⚠ 首頁**沒有**額度卡。額度在「體驗付費版 AI 工具」那一頁 ——
> 兩邊都放的話就是同一台狀態機的兩份實作。

### 1.2 體驗付費版 AI 工具（`myai.html`）

- 顯示**我的 MYAI 點數**，額度偏低／用完時整張卡變色
- 主要動作「前往 MYAI 問 AI」：先開廠商的登出頁，1 秒後轉登入頁
  （確保是這位學生登入，不是沿用上一個人的 session）
- 額度不足時給三個下一步：看用在哪、如何申請額度、**向管理員申請額度**
  （走既有的問題回報，不另開第二個收件匣）
- **初始密碼**：開通後保留期內顯示帳號與初始密碼，可一鍵複製
  - 「我已經改好密碼了」會**立即銷毀**伺服器上的暫存密碼，不可逆
  - 沒有密碼可看時整區不出現，也不留訊息

**限制**
- 彈出視窗被瀏覽器擋下時會給一個可點的連結，不會靜默失敗
- 還沒開通的人：主要動作**停用**，並給問題回報的出口

### 1.2.5 GPU 功能的身分閘門（v4.39，2026-10-06）

GPU 相關功能（訓練、程式實驗室、資料集、GPU 狀態、我的訓練）**依身分開放**。

| 旋鈕 | 預設 | 意思 |
|---|---|---|
| `gpu_features_enabled` | 1 | 總開關。0 = 全部暫停（維護用），管理員不受限 |
| `gpu_enabled_student` | 0 | 學生 |
| `gpu_enabled_teacher` | 1 | 老師 |
| `gpu_enabled_staff` | 1 | 職員 |
| `gpu_enabled_guest` | 0 | 訪客 |
| `gpu_enabled_admin` | 1 | 只是表格完整；真正的管理員判定走 `is_admin`，關掉也擋不住 |

- **判定只有一份**：`crud.gpu_access(db, user)` → `{allowed, reason}`，`reason` 是 `paused`／`role`／`None`。
  前端不自己算，讀 `/auth/me` 的 `gpu_access`（`chrome.js applyGpuGate`、`tour.js gpuEnabled`）。
- **後端也擋**（v4.39 新增，在此之前只有前端）：`auth.require_gpu` 掛在
  `POST /jobs`、`POST /lab/start`、`POST /lab/sessions`、`POST /datasets/upload`。
  取消、停止、刪除**不擋** —— 已經在跑的東西要收得掉。
- **兩種原因的文案分開**：暫停 = 等就好；身分 = 去問管理者。講一樣的話學生會一直等一個不會來的恢復。
- **一次性遷移** `migrate_gpu_role_switches`：2026-09-07 設下的 `gpu_features_enabled=0`
  （當時沒有身分概念，唯一能做的事）會被放回 1，身分政策接手。靠 `gpu_role_switches_migrated`
  記號只跑一次 —— 不然管理者自己關掉總開關後，下次開機又被搬回去。

### 1.2.6 引導導覽的路線（v4.40，2026-10-06）

首次登入自動走一遍，之後從帳號選單「再看一次導覽」。步驟表在 `web-ui-V1/tour.js` 的 `STEPS`。

```
GPU 有開放（47 步）：首頁 → MYAI → 交給平台訓練 → 程式實驗室 → 我的訓練與資料 → 使用量 → 教學與範例 → 問題回報 → 首頁
GPU 沒開放（27 步）：首頁 → MYAI → 使用量 → 教學與範例 → 問題回報 → 首頁
```

- **首頁照 1、2、3 介紹**（v4.39 修）：`ai`（第一條，純介紹）→ `train`（第二條）→ `lab`（第三條）
  → `ai_go`（點卡片換頁）。換頁一定是一頁的最後一步，所以「介紹第一條」與「點它過去」是兩步。
- **訓練頁**（v4.40 新增）：`tr_pick` 要使用者點「先體驗看看」（進場遮罩第一次關不掉，不先選就看不到表單）
  → `tr_side` 側欄 → `tr_start` 開始訓練鈕。🔴 `tr_start` **不是** click 步驟 ——
  按下去會送出一張真的訓練單、佔掉 GPU，而導覽還停在原地。
- **程式實驗室**（v4.40 新增）：`lab_hero` → `lab_start` → `lab_saves`，**全部只講不按** ——
  「啟動並開啟實驗室」會真的起容器、開新分頁，導覽當場被丟在舊分頁。
- 訓練與實驗室那 12 步**全部標 `gpu: true`**：閘門關著時 `go_train` 那座橋不在，
  但 `stepsFor` 的可達性只看「上一步是不是 click」—— 不標的話 GPU 關的人會從
  `go_usage_myai` 直接掉進訓練頁的步驟。`tests/tour.test.js` 的 `badTransitions` 守這條鏈。

### 1.3 體驗現有模型訓練（直接是 `train.html`）

v4.38（2026-10-05）起導覽列「體驗現有模型訓練」與首頁卡片**直接到 `train.html`**；原本的引導頁 `gpu.html`
只剩轉址（帶著 `?task=`／`?mode=` 轉過去，給舊書籤用）。

- **開始的方式**：一進來先蓋上**全版遮罩三選一**（第一次不能關，只能選或「回到首頁」）；選完寫進網址
  `&mode=…`，重新整理不會再跳。側欄最上面有「目前的方式＋重新選擇模式」，可以再叫出同一個遮罩（這時才有 ×／Esc）。
- **要練哪一種**：側欄的「要練哪一種」分頁（圖片分類／表格資料分類／文字分類，各附範例名）。
- **側欄**：主區塊維持置中；側欄 position:fixed 貼在主區塊左邊、不跟著捲動。放得下才固定
  （小基沒停靠：視窗 ≥ 1100px；停靠：≥ 1445px），放不下就排在表單上方一列。原本表單上方的種類切換列與體驗模式的「換一種範例」都拿掉了。
  「用自己的程式」沒有這一欄（後端有 `script_source` 就不看種類，送單也不帶 `task`）。
- **每種方式的內容是訂死的**（擁有者 2026-10-05）：先體驗看看＝只用平台範例（自動帶入）；
  用自己的資料＝自己的 zip、**沒有**範例鈕；用自己的程式＝自己的 zip＋自己的 `.py`（不可收合）、沒有範例。
  離開體驗模式時手上的範例會清掉。
- `?job=`（只看結果）不跳遮罩、也不顯示側欄；`?dataset=`（用既有資料集）不跳遮罩、固定「用自己的資料」。

三種方式（v4.36）：

| 方式 | `mode` | 適合 | 訓練頁上看得到的 |
|---|---|---|---|
| 先體驗看看 | `easy` | 第一次來 | 只有「要訓練什麼／資料／要多久」三行與開始鈕，範例自動載入 |
| 用自己的資料 | `normal` | 有資料、不想寫程式 | 壓縮檔格式、上傳、輪數（種類在左側分頁） |
| 用自己的程式 | `hard` | 會寫訓練程式 | 上傳、輪數、自訂程式（一進來就展開；沒選 `.py` 不能開始） |

原本的「學習程式碼」按鈕拿掉了，改成訓練結果下方的「想看看剛才那支程式？」——
純說明、不放連結，告訴有興趣的人到程式實驗室的 `projects` 裡找對應的範例
（實驗室每個存檔都會放好三種範例，見 `lab_manager.seed_samples`）。
`train.html` 不帶 `mode`（例如從「我的訓練」進來）＝ `normal`；`?dataset=` 一律 `normal`；`?job=` 只看結果。

`train.html` 最上面可以選三種內建訓練（v4.19，2026-09-20）：

| 種類 | 資料長什麼樣 | 範例 |
|---|---|---|
| 圖片分類 | zip 裡每個類別一個資料夾 | 貓／狗（1000 張） |
| 表格資料分類 | zip 裡一個 CSV，一欄是答案（`label` 或最後一欄） | 學生會不會及格（320 筆） |
| 文字分類 | zip 裡一個 CSV：`text`、`label` 兩欄 | 餐廳評論正／負面（240 句） |

範例只在「先體驗看看」自動帶入（v4.38 起沒有範例鈕）。表格／文字的範例由 `scripts/make_training_samples.py` 產生
（固定種子、可重現），腳本在 `gpu-worker/builtin_scripts/`，登錄表在 `crud.BUILTIN_TASKS`。

三步驟預覽（準備資料 → 在實驗室裡跑 → 看結果）是**預期管理**，不可點。

### 1.4 程式實驗室（`lab.html`）

瀏覽器裡的 VS Code（code-server）。

- **多份存檔**：可以有好幾個各自獨立的工作區，一次只開一份；
  切換時舊的會關閉，**檔案全部保留**
- **GPU 勾選**：預設不勾。勾了才佔卡，借不到時後端會講出是誰在用
- **時間限制**：借了 GPU 有最長借用時間（預設 120 分鐘），
  到期前 30／10／5 分鐘會警告，VS Code 內也看得到
- **每日額度**：依角色有每日使用時間上限，剩餘時間顯示在卡片上
- **磁碟**：顯示「用了多少 / 上限多少」，用量是即時量的不是每日快照

**限制**
- 閒置一段時間會自動關閉（檔案保留）
- 超出磁碟配額會被凍結：進得去（整理模式，讓你刪檔案），但不能用 GPU、不能開新存檔，也不能上傳資料集或送訓練任務。刪完關掉實驗室就會自動解開

### 1.5 我的訓練與資料（`jobs.html`，v4.30 合併「我的訓練進度」與「我的資料集」）

一頁兩個分頁（擁有者 2026-09-24：「這兩頁沒有區別，請整合，做 Tab 也行」）。
`datasets.html` 只剩轉址到 `jobs.html?tab=data`，舊連結不會 404。

- **訓練與模型**：送出去的訓練清單與結果。每一筆：看進度與結果／下載模型檔／取消。
  - 排隊位置只在真的排隊時顯示
  - 每個檔還在的模型寫「保留到哪一天」；被清掉的寫「模型已過保留期（哪天清的）」
    —— 靠 `training_jobs.artifact_purged_at`（v4.29）分得開「過期」與「本來就沒有」
  - 保留規則（`ARTIFACT_KEEP_PER_USER` / `ARTIFACT_TTL_DAYS`，預設 10 / 30）跟著
    `GET /jobs` 的 `retention` 回，畫面不寫死；**不算在資料的 2 GB 裡**
- **上傳的資料**：每人 2 GB。每一包：再訓練一次／**下載**（v4.29 新增）／刪除
  （還有任務在用時鈕停用並說明原因）。

### 1.8 GPU 現在忙不忙（`status.html`，v4.24）

回答一個問題：**我現在能不能用，不能的話要等多久。**

- 最上面先給結論（可以用／借不到 + 下一個開放時段），卡片是理由
- 每張卡：空閒 / 訓練任務執行中 / 程式實驗室使用中，加上顯示記憶體
- 🔴 **不顯示是誰在用** —— 只有自己的任務會帶名稱。判斷「要等還是改天」
  用不到對方是誰，知道了只會變成互相催促
- 實驗室有最長借用時間，所以說得出「預計幾點釋放」；
  **批次訓練沒有**，只說「幾點開始跑」——編一個到期時間出來比不說更糟
- 佇列：現在有幾個任務在排（大家的）＋自己的任務排第幾
- 離線的機器**不畫卡片**（那是最後一次心跳的樣子，不是現況），
  但「機器狀態」那一區會說它離線了
- 自動更新 20 秒一次，分頁切走就停（不要做無人在看的輪詢）
- ⚠ GPU 功能暫停（`gpu_features_enabled=0`）時，這一頁與其他 GPU 頁一起被擋 ——
  一個「現在很空閒」的狀態頁只會讓人以為可以用，然後在下一步被擋下來

### 1.9 到訪人次（登入頁與首頁的頁尾，v4.24）

本日 / 本月 / 累計三個數字。

- 🔴 是**人次**不是人數：同一位訪客**當天**只算一次，隔天再來會再算一次。
  介面上的字也是這樣寫 —— 寫成「人數」的話，一個每天來的人會讓數字每天 +1，
  看的人會以為那是新的人。
- **登入頁也有**（而且那才是門面）：首頁沒登入會被導去登入頁，
  所以未登入訪客看到的是登入頁那一塊。
- 去重靠一個放在瀏覽器 localStorage 的**隨機 id**（不是 IP）——
  校園是 NAT，只看 IP 會把整棟樓算成一個人。清掉瀏覽器資料的人會被重新算一次。
- ⚠ 這個數字是「大概有多少人來過」，**不是稽核級的計數**：
  前端的 id 可以被清掉也可以被偽造。要防灌水就得登入才算，
  而那會把「有多少人看過首頁」這個問題本身消滅掉。

## 2. 管理端

五個分頁：總覽、帳號、平台設定、訊息、數據。

### 2.1 帳號

- 使用者清單（本機 / SSO 兩種來源分頁）
- 建立、停用、刪除、改角色與管理權限
- **臨時帳號**：給校外人士、長官視察用，到期自動停用
- **廠商帳號對應**：同步 MYAI 帳號、自動配對、CSV 批次建立對應
- 個別加點、強制關閉某人的實驗室

> ⚠ **刪除帳號**會把 Lab 存檔封存（期限內可還原），其餘資料消失。

### 2.2 平台設定

| 區塊 | 內容 |
|---|---|
| 營運設定 | 7 個旋鈕，**改完立刻生效不用重啟** |
| 告警信 | 系統自己出事時寄給誰（收件人全部留空 = 完全不寄） |
| 模型 | 可用的模型清單 |
| GPU 節點 | 每台節點的狀態、可排程時段、開關、池別覆蓋 |
| 外部 AI | 小基用哪個模型 |
| 廠商模型代碼對應 | 把廠商的原始代碼（如 `gpt_5_6_sol`）翻成看得懂的名字 |
| 手動補齊點數 | 把所有綁定帳號補到同一個水位 |
| 組織對照表 | 學系 → 學院 / 行政單位 / 校區，可匯出匯入 |

**設定分四組**：平台營運、MYAI 廠商整合、小基（RAG）、寄信（SMTP）。

> 🔴 有**兩個設定刻意從畫面隱藏**：`monthly_token_limit` 與 `token_reset_day`。
> 它們是**平台自己的** Token 額度，與學生在用的 MYAI 點數無關 ——
> 並排時接手的人會以為調它們就能改學生的額度，而調了不會有任何效果。
> 隱藏 ≠ 停用：那兩個功能照常運作。要調請改 `.env`。

### 2.3 訊息

- **問題回報**：清單、彈窗檢視、回覆、改狀態、依類別篩選
- **公告**：新增／編輯（彈窗）、置頂、公開與否、**中英兩版並排編輯**、附件

### 2.4 數據

| 區塊 | 內容 |
|---|---|
| MYAI 點數消耗 | 來自廠商交易日誌，逐筆含模型 |
| 訓練任務 | 送出的任務統計 |
| **各分類使用** | 依學系／學院／行政單位分組的使用數據與兩種比例 |

各分類那張表的欄位分兩塊：

```
        │      這一組的人       │            用了多少
 學系   │ 人數 │ 有用的人 │ 滲透率 │ MYAI次數 │ MYAI點數 │ 訓練 │ Lab·GPU │ Lab·CPU │ 登入 │ Token
```

- **佔比**（括號裡的 %）= 這一組佔全平台的幾 % → 看「誰貢獻最多」
- **滲透率** = 有用的人 ÷ 這一組在平台上的人數 → 看「哪一組還沒推開」

> ⚠ 三件事文件與介面都要講明：
> 1. **滲透率的分母是「登入過平台的人」**，不是全系人數 —— 這個數字偏高
> 2. **「有用的人」是下限** —— 跨四張表去重在資料庫端做不到，取各項最大值
> 3. **MYAI 次數與 Lab 的 GPU/CPU 之分是 2026-08-30 才開始記的** ——
>    在那之前的 0 是「還沒開始記」，不是「沒有人用」

## 3. 系統邊界（刻意不做的事）

這一節列的**不是待辦**，是決定。日後想改請先看理由。

| 事 | 為什麼不做 |
|---|---|
| 問題回報不通知使用者 | 通知的成本落在管理員身上，而回報量不大 |
| 文件庫沒內容時不出現入口 | 連到空頁比沒有連結更糟 |
| 公告附件不接受 `.html` / `.svg` | 那兩種會在**我們自己的網域下**執行 script |
| 公告附件刪除不封存 | 那是管理員手上已經有的東西的副本，不像 Lab 存檔沒了救不回 |
| 行政單位不顯示英文名 | 英文名只有 53/97，做了會讓同一欄一半英文一半中文 |
| 不記錄跳轉來源 IP | 統計要回答「哪個系在用」，`user_id` 就推得出來 |
| 不預測 email 真假 | 有地址就寄，退件才是事實 |
