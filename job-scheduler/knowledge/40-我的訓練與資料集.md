# 「我的訓練」這一頁是做什麼的

最上面那排的 **「我的訓練」**。你送出過的訓練都在這裡，
點進去可以看進度與結果，**跑完的可以下載模型**。

上方有兩個篩選：**全部** 與 **訓練中**（排隊中的也算在裡面 ——
只要還沒跑完就會出現在這個篩選底下）。
下方有「開始一個新的訓練」與「我的資料集」的入口。

# 訓練任務有哪些狀態

一共五種，卡片上會直接寫：

- **排隊中** —— 已經送出，還在等機器。
- **訓練中** —— 正在跑。
- **完成** —— 跑完了，可以下載模型。
- **失敗** —— 中途出錯，卡片上會顯示錯誤訊息。
- **已取消** —— 你（或管理者）把它取消了。

# 我可以取消訓練嗎

可以。**排隊中**與**訓練中**的任務都可以取消（2026-09-20 起；以前只有排隊中的可以）。
訓練中的取消後，機器上的訓練會在幾秒內被停掉，不會繼續佔著 GPU。

取消之後狀態會變成「已取消」，紀錄仍然留著，不會消失。
已經「完成」「失敗」「已取消」的任務不能再取消（它們已經結束了）。

# 交給平台訓練可以訓練哪些東西

「交給平台訓練」頁面最上面可以選三種（2026-09-20 起）：

- **圖片分類** —— 上傳一包分好類的圖片（每個類別一個資料夾），例如貓／狗。
- **表格資料分類** —— 上傳一份 CSV（壓成 zip），每一列一筆資料，其中一欄是答案
  （欄名叫 label，或放在最後一欄）。例如用讀書時數、出席率預測會不會及格。
- **文字分類** —— 上傳一份 CSV（壓成 zip），兩欄：句子（text）與答案（label）。
  例如把餐廳評論分成正面／負面。中英文都可以，不需要下載任何語言模型。

三種都不用寫程式。沒有自己的資料的話，每一種都有「用平台準備好的範例」可以直接試。

# 表格或文字的 CSV 有什麼要求

- zip 裡放**一個** CSV（多包一層資料夾沒關係）。
- 第一列是欄名。答案欄叫 `label`（或 target / class / 答案 / 類別），找不到就用最後一欄。
- 答案至少要有**兩種**不同的值，每種至少幾十筆。
- 編碼用 UTF-8（Excel：另存新檔 → CSV UTF-8）；cp950 的也讀得到，但建議 UTF-8。
- 表格分類：數字欄直接用，文字欄會自動轉成類別，缺值會自動補；
  每一列都不一樣的欄（像學號、姓名）會自動略過。
- 文字分類：文字欄叫 `text`（或 sentence / content / 句子 / 內容），找不到就用第一個不是答案的欄。

# 訓練完成後怎麼拿到模型

在「我的訓練」點進那一筆，裡面有下載。
如果你用的是自訂訓練程式，模型要先由你的程式存到 `/workspace/output` 才會有東西可以下載。

# 訓練失敗，卡片上的錯誤訊息看不懂

失敗的卡片會直接顯示錯誤訊息。如果那句話看不出原因，
到「交給平台訓練」頁面下方的 **「訓練紀錄」** 看完整輸出，
再用「問題回報」把那一段貼給管理者。

# 「我的資料集」這一頁是做什麼的

最上面那排的 **「我的資料集」**。你上傳過的資料包（圖片、表格或文字）都在這裡，
可以**直接拿來再訓練一次**，或**刪掉騰出空間**。

頁面上方會顯示你已經用掉多少空間、上限多少。

# 我可以重複用同一包資料訓練嗎

可以，這正是「我的資料集」存在的原因 ——
不用為了換個輪數或換支訓練程式就重傳一次 2 GB。

到「我的資料集」，在那一包上選擇再訓練一次即可。

# 空間不夠了怎麼辦

到 **「我的資料集」** 把用不到的資料包刪掉。
刪掉之後空間立刻釋放。

⚠️ 刪掉資料集**不會**刪掉已經訓練好的模型，
但那一包資料就不能再拿來重新訓練了。

# 「我的資料集」說「還沒有上傳過任何資料集」

就是字面意思：你還沒上傳過。
按下方的「上傳新的一包，開始訓練」就會帶你到上傳頁。

如果你明明傳過卻看到這句話，先重新整理一次；
還是這樣就用「問題回報」告訴管理者。

# 「暫時讀不到你的訓練紀錄」是什麼意思

那是**畫面暫時拿不到資料**，不是你的東西不見了。
訊息裡也寫了「這不代表它們不見了，稍後重新整理即可」。

先重新整理。如果一直這樣，用「問題回報」告訴管理者。
