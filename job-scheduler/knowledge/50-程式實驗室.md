# 程式實驗室是什麼

最上面那排的 **「程式實驗室」**（英文介面叫 **Code Lab**）。

它是**瀏覽器裡的 VS Code** —— 不用在自己電腦上裝任何東西，
開啟就能寫程式、跑程式、看檔案。頁面上的說明是：
「瀏覽器裡的 VS Code。檔案永久保留，閒置一段時間會自動關閉。」

⚠️ 舊的文件或截圖可能把它叫做「Notebook」或「AI Base Lab」，
現在介面上一律叫**程式實驗室**。

# 程式實驗室可以用 GPU 嗎

可以，但要**主動勾選**。在程式實驗室頁面按開啟之前，勾「這次要用 GPU（訓練模型才需要）」。

不勾的話是一般（CPU）實驗室 —— 一樣可以寫程式、裝套件、跑不需要顯示卡的東西。

⚠️ **GPU 全校只有一張，同時只能一個人用。** 用完請按「關閉實驗室」讓給下一位。

# GPU 實驗室裡有裝什麼

勾了 GPU 之後開的是另一個環境，裡面**已經裝好**：

- **PyTorch 2.7 + CUDA 12.8**（`torch.cuda.is_available()` 會是 `True`）
- numpy、pandas、matplotlib、seaborn、scikit-learn
- 與「交給平台訓練」用的是**同一套版本** —— 在實驗室裡跑得動的程式，送去平台訓練也跑得動。

一般（CPU）實驗室裡**沒有**這些，需要的話要自己 `pip install`。

# 為什麼我開不了 GPU 實驗室

畫面會告訴你原因，只有兩種：

- **「GPU 正在被另一個人的程式實驗室使用中」** —— 有人正開著 GPU 實驗室。
  等他關掉，或先開一般（CPU）實驗室。
- **「GPU 正在跑訓練任務」** —— 有人送了「交給平台訓練」的任務正在跑。
  任務跑完就會放開。

兩種都**不是故障**，不用回報問題。系統不會幫你排隊，請稍後再按一次。

# 我開著 GPU 實驗室會影響別人嗎

會。你佔著那張卡的時候：

- 別人開不了 GPU 實驗室。
- 別人送出的「交給平台訓練」任務會**留在佇列裡等**（不會失敗，你一關掉就會開始跑）。

所以請**用完就關**。學生單次最長 90 分鐘會自動關閉，但不要等它自動關。

# 我怎麼知道自己正佔著 GPU

程式實驗室頁面會顯示一句「這一份實驗室正在使用 GPU。用完請按『關閉實驗室』讓給下一位。」

沒有那句話就表示你開的是一般實驗室，沒有佔用任何人的資源。

# 已經開著的實驗室可以中途加上 GPU 嗎

不行。容器啟動之後不能改裝置。

要換成 GPU 版的話：先按「關閉實驗室」，再勾選 GPU 重新開啟。**檔案都會保留**，
因為兩種實驗室掛的是同一份你的工作區。

# 怎麼開程式實驗室

按最上面那排的「程式實驗室」進去，頁面上會顯示目前狀態，按下開啟即可。
第一次開需要一點時間準備環境。

如果你完全沒寫過，先看首頁的「訓練你的第一個模型」——
那條路會幫你開好實驗室，而且裡面已經有寫好的程式可以逐格執行。

# 「我的存檔」是什麼，可以開幾份

**存檔就是各自獨立的工作區。** 你可以有好幾份，
例如一份放課堂作業、一份放專題。

⚠️ **一次只能開一份。** 切換到另一份的時候，
舊的那份會被關閉，但**檔案都保留**，不會不見。

在程式實驗室頁面的「我的存檔」區塊可以「新增一份存檔」或切換。

# 我的檔案會被刪掉嗎

**不會，檔案永久保留。** 實驗室因為閒置而自動關閉、
或你切換到別的存檔，檔案都還在，下次開起來就看得到。

唯一的例外是**帳號被刪除**：那時 Lab 資料會先封存一段時間（預設 30 天）才真的清掉，
而且銷毀之前平台會寄信提醒你。

# 實驗室為什麼會自己關掉

因為**閒置**。不同身分的時間限制不一樣：

- **學生** —— 閒置 **30 分鐘**自動關閉；單次最長 **90 分鐘**；每天累積上限 **6 小時**。
- **教師** —— 閒置 **120 分鐘**自動關閉；沒有單次與每日上限。
- **管理員** —— 沒有時間限制。

被關掉不會遺失檔案，重新開啟即可。

# 「今日剩餘時間」是什麼

程式實驗室頁面上的一個數字，表示**你今天還可以用幾分鐘**。
學生每天的額度是 6 小時（360 分鐘），用完就要等隔天。

同一頁還會顯示「已執行」（這次開了多久）與「磁碟配額」。

# 磁碟配額是多少

依身分不同：

- **學生** —— 10 GB
- **教師** —— 50 GB
- **管理員** —— 100 GB

管理者可以另外幫個別使用者加額度，所以你看到的數字可能比上面大。
實際數字以程式實驗室頁面顯示的「磁碟配額」為準。

# 空間不夠用怎麼辦

先在實驗室裡刪掉用不到的檔案（特別是資料集與模型檔，那些最占空間）。
真的需要更多，用「問題回報」向管理者申請，說明用途與需要多少。

# 怎麼手動關閉實驗室

程式實驗室頁面上有 **「關閉實驗室」**。
用完主動關掉是好習慣 —— 那會把今日剩餘時間留給之後的自己，也把機器讓給別人。

# 實驗室裡可以裝套件嗎

可以，在實驗室裡開終端機用 `pip install` 安裝即可。

⚠️ 裝在存檔工作區裡的東西會跟著保留，但如果你切換到**另一份存檔**，
那邊是獨立的環境，要重裝一次。

# 訓練程式在實驗室裡怎麼跑

如果你是照「訓練你的第一個模型」進來的，實驗室裡已經有寫好的程式，**逐格執行**即可。

如果你想把程式交給平台在 GPU 上跑（而不是在實驗室裡跑），
那要用「交給平台訓練」的「我要用自己的訓練程式」，
路徑與環境變數的約定寫在「訓練模型」那一份說明裡。
