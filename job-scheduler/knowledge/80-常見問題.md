# 我該用哪一個功能

看你想做什麼：

- **想問 AI、翻譯、做簡報** → 導覽列「想做點什麼」裡的「體驗大模型」。
- **想寫程式** → 「程式實驗室」。
- **想訓練影像分類模型，但不想寫程式** → 「交給平台訓練」。
- **想訓練，而且要用自己的程式** → 「交給平台訓練」裡的「我要用自己的訓練程式」。
- **想一邊改一邊看結果地訓練** → 「程式實驗室」並**勾選 GPU**。
- **完全沒概念，想先試一次** → 導覽列「想做點什麼」裡的「體驗現有模型訓練」。

# 程式實驗室和「交給平台訓練」差在哪

- **程式實驗室** —— 你**自己在瀏覽器裡跑**。適合寫程式、除錯、互動式地試模型。
  有閒置時間與每日時數限制。勾了 GPU 就能在裡面用顯示卡，
  但**全校只有一張**，同時只有一個人能用，所以用完要關。
- **交給平台訓練** —— 送到 **GPU 節點上跑**，你可以關掉瀏覽器去做別的事，
  跑完回「我的訓練進度」看結果。適合真的要花時間的訓練。

簡單說：**要互動就用實驗室，要跑久就交給平台。**

# 畫面上有一段紅色的訊息

紅色代表**出錯了**，訊息裡通常會寫原因。常見的幾種：

- 「暫時取不到…」 → 畫面拿不到資料，**不代表你的東西不見了**，重新整理再試。
- 「你的登入已經過期」 → 重新登入即可。
- 「存不起來（…）」 → 括號裡是原因，看不懂就用問題回報把整句貼過去。

淡色（不是紅的）那種是**正常訊息**，例如「已儲存」「目前沒有公告」，不是錯誤。

# 我改了東西但畫面沒變

先**重新整理**一次。如果還是舊的，試著**強制重新整理**
（Windows 按 `Ctrl+F5`，Mac 按 `Cmd+Shift+R`）。

如果仍然不對，用「問題回報」，並在描述裡寫清楚你做了什麼、看到什麼。

# 平台顯示的時間是哪個時區

**一律是台灣時間（Asia/Taipei）**，不會跟著你電腦的時區跑。

⚠️ 例外：使用量明細裡的 MYAI 交易時間來自廠商，以那邊的時間為準。

# 手機可以用嗎

目前**主要是給電腦用的**，手機版尚未開放。
請用桌機或筆電的瀏覽器。

# 有人可以看到我的檔案或對話嗎

- **程式實驗室裡的檔案** —— 是你自己的工作區，其他使用者看不到。
- **問題回報** —— 管理者看得到你送出的內容與那一頁列出的診斷資訊。
- **使用量統計** —— 管理者看得到整體與分群的統計。
- **跟我（小基）的對話** —— 「程式家教」模式你**主動附加**的檔案才會被讀到，
  我不會自己去翻你的檔案。

# 我的身分或系所寫錯了

用「問題回報」告訴管理者，他可以直接改。
身分是登入時依信箱網域自動判定的，自己改不了。

# 帳號被刪掉了會怎樣

程式實驗室的資料會**先封存一段時間**（預設 30 天）才真的清掉，
在那之前還原得回來。銷毀之前平台會寄信提醒你。

如果是誤刪，**盡快**用信件或其他管道聯絡管理者，越早越好。

# 為什麼我收到平台寄來的信

平台會在這幾種情況寄信給你：

- 登入提醒。
- MYAI 點數快用完或已用完。
- 程式實驗室資料即將銷毀的提醒（第一次與最後一次）。

信件都是**中英雙語**，主旨會寫成「中文 | English」的形式。

# 我想申請更多資源

用「問題回報」向管理者說明，寫清楚：

- 你要的是什麼（磁碟空間、實驗室時數、MYAI 點數）。
- 用途是什麼（哪一門課、什麼專題）。
- 大概需要多少、用到什麼時候。

寫得越具體越容易通過。
