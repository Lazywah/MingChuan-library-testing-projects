# 小基是誰

我就是小基，這個平台的助手。畫面右邊那個聊天視窗就是我。
我有兩種模式，用視窗上方的兩顆按鈕切換：

- **客服** —— 回答平台操作問題（怎麼登入、怎麼提交訓練、程式實驗室怎麼用）。
  這個模式**不需要登入也能用**，登入頁上也有。
- **程式家教** —— 陪你看程式碼、找錯、解釋為什麼。**需要登入**。

# 小基會扣我的點數嗎

**不會。** 問我不消耗 MYAI 點數。

點數只有你去 MYAI 平台使用 AI 工具時才會扣。

# 程式家教模式怎麼用

切到「程式家教」分頁之後：

- 直接把程式碼貼進對話框，或
- 用上方的 **「📎 附加 Lab 檔案」** 把你程式實驗室裡的檔案帶進來。

附加是**你自己挑選**的，我不會自己去翻你的檔案。

我會先講問題出在哪、為什麼，再給修正 —— 不會只丟一份答案給你。

# 小基答不出來的時候

我只根據平台的官方說明回答。**說明裡沒寫的，我會直接說我不確定**，
不會憑印象編一個答案給你 —— 那比不回答更糟。

遇到這種情況請用 **「問題回報」**，那會直接送到管理者手上。

# 小基說「AI 服務尚未啟動」

表示背後的模型服務目前沒有在跑，不是你的問題。
這種情況請用「問題回報」告訴管理者，或稍後再試。

# 問題回報怎麼用

導覽列「不知道怎麼做」裡的 **「問題回報」**（首頁同一組的卡片也是它）。

1. 在「發生了什麼事」填寫問題。寫得越具體越好 ——
   你按了什麼、預期看到什麼、實際看到什麼。
2. 按「送出回報」。

# 送出回報之後會怎樣

- 管理者會在管理介面看到你的回報。
- **不會另外寄信通知你。**
- **回覆會出現在同一頁下方的「我的回報」。** 想看有沒有人回，回到這一頁看。

每一則回報會顯示狀態：**未處理／處理中／已解決**。

# 回報會送出我的什麼資料

送出前那一頁會列出「會一起送出的診斷資訊」，**你看得到才會送**：

時間、你的使用者名稱與代號、介面版本、來源頁、網址、瀏覽器、語言、視窗大小、配色。

平台**不會**收集你在那一頁上看不到的東西。

# 我不想用表單，可以自己拿給管理者嗎

可以。問題回報頁有 **「改用複製，自己交給管理者」** ——
按下去會把描述與診斷資訊一起複製起來，你可以貼到信件或訊息裡自己送。

# 剪貼簿不能用，複製失敗

有些瀏覽器會擋自動複製。這時畫面會說
「這個瀏覽器不允許自動複製。已經幫你選起來了，按 Ctrl+C 複製。」

照著按 `Ctrl+C`（Mac 是 `Cmd+C`）即可，文字已經幫你選好了。
