# 我想訓練一個模型，要從哪裡開始

首頁的 **「訓練你的第一個影像分類模型」**。
那一頁會用「做出一個能分辨貓和狗的模型」帶你走，大約 20 分鐘。

到那裡之後有兩條路，看你想不想寫程式：

- **不想寫程式** → 按「我有分好類的圖片，交給平台訓練」，上傳一包 zip 就好。
- **想自己寫** → 按「我已經有資料了，直接開實驗室」，在程式實驗室裡逐格執行。

沒有自己的圖片也沒關係，那一頁有平台準備好的範例可以直接用。

# 「交給平台訓練」怎麼用

到 **「交給平台訓練」** 頁面，三個步驟：

1. 把整理好的 **zip** 拖進上傳區，或點一下選檔案。
2. 填「要練幾輪」（epochs）。不確定就用預設的 **10**。
3. 按「開始訓練」。

送出後同一頁會顯示**訓練進度**、**每一輪的結果**，
以及一份**訓練紀錄**（出問題時把它貼給管理者）。

# 訓練用的壓縮檔要長什麼樣子

**每個類別一個資料夾，圖片放進去，整包壓成 zip。資料夾的名字就是類別的名字。**

```
我的資料.zip
├── 貓/
│   ├── 001.jpg
│   └── 002.jpg
└── 狗/
    ├── 001.jpg
    └── 002.jpg
```

- 外面多包一層資料夾**也沒關係**，平台會自己往下找。
- **至少要兩個類別**，只有一類沒辦法訓練分類模型。

# 上傳的檔案有什麼限制

- **只收 `.zip`**，其他格式（rar、7z、資料夾直接拖）都不行。
- **每人上限 2 GB**。
- 檔案太大或格式不對時，畫面會直接告訴你，並且寫出你的檔案實際多大。

# 「要練幾輪」該填多少

預設 **10**，不確定就用它。

「輪」就是 epochs —— 同一批圖片重複學幾遍。
**練越多輪越久，也不一定越準**：練過頭反而會讓模型只背住訓練圖片。
先用 10 跑一次看結果，再決定要不要調。

# 我想用自己的訓練程式，可以嗎

可以。在「交給平台訓練」頁面展開 **「我要用自己的訓練程式」**，選一支 `.py` 上傳。
平台會把資料準備好、把你的程式跑起來，其餘由你的程式決定。

約定好的路徑與變數：

- `/workspace/dataset` —— 你的資料，**唯讀**。
- `/workspace/output` —— **把模型存到這裡**，訓練完才拿得到。
- 環境變數：`DATASET_DIR`、`OUTPUT_DIR`、`EPOCHS`。

# 自訂訓練程式怎麼回報進度和錯誤

平台是**讀你程式印出來的文字**來判斷的：

- **進度** —— 印出 `Epoch 3/10` 這種格式，畫面就會顯示進度條。
- **失敗** —— 印出以 `[錯誤]` 開頭的那一行，它會成為畫面上的錯誤訊息。

所以要讓使用者看得懂為什麼失敗，就用 `[錯誤] ...` 把原因印出來。

# 訓練會跑多久，有時間上限嗎

單一任務的時間上限預設是 **120 分鐘**，超過會自動停止。
這個值由管理者設定，可能與此不同。

實際跑多久看資料量與輪數。用平台範例走完大約 20 分鐘。

# 送出訓練之後要在哪裡看

兩個地方都可以：

- **「交給平台訓練」那一頁** —— 送出後就停在那裡看進度與每一輪的結果。
- **「我的訓練」** —— 最上面那排的分頁，你送出過的每一筆都在裡面。

訓練完成後可以下載模型。

# 訓練失敗了怎麼查

「交給平台訓練」頁面下方有 **「訓練紀錄」**，那是完整的執行輸出。
出問題時把那一段複製起來，用「問題回報」貼給管理者，
他才有辦法判斷是資料的問題還是平台的問題。

# 目前沒有可用算力是什麼意思

「訓練你的第一個模型」那一頁如果顯示 **「目前無可用算力／等待機器上線」**，
表示現在沒有 GPU 節點在線上，或是目前不在開放時段。

這時送出的任務會排隊，等機器上線再跑；
如果急著用，用「問題回報」問管理者什麼時候會開。
