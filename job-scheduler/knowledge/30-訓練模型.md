# 我想訓練一個模型，要從哪裡開始

導覽列「AI 工具一把罩」裡的 **「體驗現有模型訓練」**（首頁同一組的第二張卡片也是它）。

那一頁先選一種範例（貓狗圖片／學生及格表格／餐廳評論文字），再選一種開始的方式：

- **先體驗看看** —— 第一次來就選這個。用平台準備好的範例，按一下「開始訓練」就好，什麼都不用準備。
  圖片範例通常不到一分鐘跑完，表格和文字大約十幾秒（GPU 忙的時候要先排隊）。
- **用自己的資料** —— 有一包整理好的 zip，平台幫你訓練，不用寫程式。
- **用自己的程式** —— 會寫訓練程式，上傳一支 `.py` 和一份資料，借學校的 GPU 跑。

在「先體驗看看」裡想改東西的話，按底下的「我想自己調（用自己的資料、改輪數、用自己的程式）」，
同一頁就會展開完整的選項，已經選好的範例不用重選。

# 想看訓練程式是怎麼寫的

用平台內建的程式訓練完，結果下面會有一段「想看看剛才那支程式？」。
程式實驗室裡有做同樣事情的範例：到首頁的「程式實驗室」，按「啟動並開啟實驗室」，
左邊 `projects` 資料夾裡就有（貓狗：`cat_dog_data/` 與 `sample_cats_dogs.py`；
表格：`students.csv` 與 `sample_tabular.py`；文字：`reviews.csv` 與 `sample_text.py`）。

在檔案上按右鍵「Run on GPU」就會在 GPU 上跑一次，可以改裡面的數字（例如 EPOCHS）再跑看看。
**不要直接按右上角的 ▶** —— 實驗室本身沒有裝訓練用的套件，那樣會失敗。

# 實驗室裡的範例不見了／找不到 cat_dog_data

貓狗範例（`cat_dog_data/` 與 `sample_cats_dogs.py`）是在你的實驗室**第一次啟動**時放進工作區的，
之後不會再自動補回來——所以如果被刪掉或改壞了，重新開實驗室也不會回來。
要救回來，在實驗室的終端機（Terminal）執行：

```
cp -r /opt/aibase/samples/. ~/projects/
```

表格與文字的範例（`students.csv`、`sample_tabular.py`、`reviews.csv`、`sample_text.py`）
是開實驗室時放進去的，同樣**只放一次**，也**不會蓋掉你改過的檔**。
要救回原版：把 `projects` 裡想還原的那個檔刪掉（或改名），再把 `projects` 裡的
`.samples-seeded-v2` 也刪掉，然後關掉實驗室再開一次 —— 缺的檔會補回原版，你其他的檔案不受影響。

# 「交給平台訓練」怎麼用

到 **「交給平台訓練」** 頁面。最上面可以切換三種方式（先體驗看看／用自己的資料／用自己的程式）；
從「體驗現有模型訓練」那一頁進來時，會停在你在那一頁選的那一種。

「先體驗看看」只有一個步驟：按「開始訓練」（範例已經自動放好）。

「用自己的資料」四個步驟：

1. 最上面先選**種類**：圖片分類、表格資料分類、文字分類（2026-09-20 起有三種）。
2. 把整理好的 **zip** 拖進上傳區，或點一下選檔案；沒有資料就按「用平台準備好的範例」。
3. 填「要練幾輪」（epochs）。不確定就用預設值（圖片 10、表格 30、文字 20）。
4. 按「開始訓練」。

送出後同一頁會顯示**訓練進度**、**每一輪的結果**，
以及一份**訓練紀錄**（出問題時把它貼給管理者）。

# 訓練用的壓縮檔要長什麼樣子

看你選的種類。

**圖片分類：每個類別一個資料夾，圖片放進去，整包壓成 zip。資料夾的名字就是類別的名字。**

```
我的資料.zip
├── 貓/
│   ├── 001.jpg
│   └── 002.jpg
└── 狗/
    ├── 001.jpg
    └── 002.jpg
```

- 外面多包一層資料夾**也沒關係**，平台會自己往下找。
- **至少要兩個類別**，只有一類沒辦法訓練分類模型。

**表格資料分類：zip 裡放一個 CSV，其中一欄是答案。**

```
學生資料.zip
└── students.csv
      study_hours,attendance,midterm,label
      3.5,0.9,72,pass
      1.0,0.4,40,fail
```

- 答案欄叫 `label`（或 target / class / 答案 / 類別），找不到就用**最後一欄**。
- 數字欄直接用，文字欄自動轉成類別，缺值自動補；每列都不同的欄（學號、姓名）會自動略過。

**文字分類：zip 裡放一個 CSV，兩欄：句子與答案。**

```
評論.zip
└── reviews.csv
      text,label
      這家店的服務很好，會再來,正面
      等了四十分鐘餐還沒來,負面
```

- 中英文都可以，不需要下載任何語言模型。
- 表格與文字都是：答案至少兩種，每種至少幾十筆；CSV 建議 UTF-8（Excel：另存新檔 → CSV UTF-8）。

# 上傳的檔案有什麼限制

- **只收 `.zip`**，其他格式（rar、7z、資料夾直接拖）都不行。
- **每人上限 2 GB**。
- 檔案太大或格式不對時，畫面會直接告訴你，並且寫出你的檔案實際多大。

# 「要練幾輪」該填多少

不確定就用預設值：圖片 **10**、表格 **30**、文字 **20**（選種類時會自動帶入）。

「輪」就是 epochs —— 同一批資料重複學幾遍。
**練越多輪越久，也不一定越準**：練過頭反而會讓模型只背住訓練圖片。
先用預設值跑一次看結果，再決定要不要調。

# 我想用自己的訓練程式，可以嗎

可以。在「交給平台訓練」頁面最上面選「用自己的程式」（或在「體驗現有模型訓練」那一頁
選「用自己的程式」那張卡），**「我要用自己的訓練程式」**那一區會直接展開，選一支 `.py` 上傳。
選了程式之後才能按「開始訓練」；資料可以用自己的 zip，也可以按「用平台準備好的範例」。
平台會把資料準備好、把你的程式跑起來，其餘由你的程式決定。

約定好的路徑與變數：

- `/workspace/dataset` —— 你的資料，**唯讀**。
- `/workspace/output` —— **把模型存到這裡**，訓練完才拿得到。
- 環境變數：`DATASET_DIR`、`OUTPUT_DIR`、`EPOCHS`。

# 自訂訓練程式怎麼回報進度和錯誤

平台是**讀你程式印出來的文字**來判斷的：

- **進度** —— 印出 `Epoch 3/10` 這種格式，畫面就會顯示進度條。
- **失敗** —— 印出以 `[錯誤]` 開頭的那一行，它會成為畫面上的錯誤訊息。

所以要讓使用者看得懂為什麼失敗，就用 `[錯誤] ...` 把原因印出來。

# 訓練會跑多久，有時間上限嗎

單一任務的時間上限預設是 **120 分鐘**，超過會自動停止。
這個值由管理者設定，可能與此不同。

實際跑多久看資料量與輪數。用平台的範例的話，圖片通常不到一分鐘、表格和文字大約十幾秒
（GPU 忙的時候要先排隊）。

# 送出訓練之後要在哪裡看

兩個地方都可以：

- **「交給平台訓練」那一頁** —— 送出後就停在那裡看進度與每一輪的結果。
- **「我的訓練」** —— 最上面那排的分頁，你送出過的每一筆都在裡面。

訓練完成後可以下載模型。

# 訓練失敗了怎麼查

「交給平台訓練」頁面下方有 **「訓練紀錄」**，那是完整的執行輸出。
出問題時把那一段複製起來，用「問題回報」貼給管理者，
他才有辦法判斷是資料的問題還是平台的問題。

# 目前沒有可用算力是什麼意思

「訓練你的第一個模型」那一頁如果顯示 **「目前無可用算力／等待機器上線」**，
表示現在沒有 GPU 節點在線上，或是目前不在開放時段。

這時送出的任務會排隊，等機器上線再跑；
如果急著用，用「問題回報」問管理者什麼時候會開。
